# Doodle illustrations

`laying.svg`, `sittingreading.svg`, `zombieing.svg` and `meditating.svg` are from
[Open Doodles](https://www.opendoodles.com) by Pablo Stanley, released under CC0
(free for any use, no attribution required; credited here anyway).

They were converted to plain SVG from the MIT-licensed `react-open-doodles@1.0.5`
npm package. Colours are CSS variables: `--ink-c` (lines) and `--accent-c` (fill),
so each screen can theme them.
